# Dive Day Checklist 2.0

A mobile-friendly reusable dive checklist with all 44 items, editable dive information, section progress, full text export, two reset options, local browser saving and an offline service worker.

Enable GitHub Pages in repository Settings → Pages → Deploy from a branch → main / (root).

On iPhone, visit the published HTTPS URL in Safari, use Share → Add to Home Screen, then open once online and test in airplane mode. Data stays in local browser storage and does not synchronize across devices.

IMPORTANT: Complete real buddy and equipment verification before diving. Checking an item does not substitute for the physical check.
